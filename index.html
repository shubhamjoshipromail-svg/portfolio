A control plane for AI agents that can use real tools while keeping permissions, budgets, and approval rules outside the prompt.

Teams can let an AI draft, search, or act while keeping consequential steps behind enforceable rules and human approval.

What I owned

Solo project · Product direction, system architecture, frontend, backend, policy engine, integrations, and test suite.

Hard problem

Durable execution semantics: a crashed worker cannot fire the same real world action twice, and an approval cannot silently bypass current policy.

Key decision

Permissions are resolved and clamped on the server. Prompt text can request capability; it cannot grant capability.

Boundary

Prototype, not a production security product. Arbitrary external MCP execution and isolated runtime containers remain unbuilt.

03Applied machine learningModel deployed

OpsPilot

A support routing copilot where redesigning the labels mattered more than another round of model tuning.

In plain English

It reads a support request, recommends the right operating queue, and sends uncertain or sensitive cases back to a person.

52.3% → 73.1%ModernBERT7 operational queues

Trained and deployed a ModernBERT classifier, diagnosed overlapping support categories, redesigned a taxonomy of ten labels into seven operational queues, and added human review based on confidence.

What I owned

Solo project · Dataset pipeline, taxonomy redesign, ModernBERT training, evaluation, model publication, and product integration.

Dataset

23,747 English support tickets from a public labeled dataset, split deterministically for training, validation, and evaluation workflows.

Diagnosis

The original ten queues overlapped operationally. Technical, product, IT, and general support often described the same underlying work.

Key decision

Merged the taxonomy into seven operational parent queues before further tuning, improving validation accuracy from 52.3% to 73.1%.

Model evidence

The public Hugging Face artifact contains ModernBERT weights, tokenizer, label mapping, training configuration, and checkpoint history.

Human boundary

Confidence and policy rules determine whether routing is suggested automatically or returned for human or supervisor review.

Boundary

73.1% is validation accuracy for the model with seven labels, not evidence of production performance on a company's live support distribution.

04Generative productPersonal project / 2026

Vibe Curator

An AI native creative environment where generated media stays editable instead of ending as a flattened file.

In plain English

You describe a visual world, then keep shaping its image, motion, atmosphere, and music instead of downloading one finished output.

4 AI providersWebGL compositorEditable scene graph

Designed and built the product because I wanted it: generated images, music, video, and guarded shaders enter the same persistent editor with source awareness and a full screen player.

Live app ↗Source ↗
SourceTreatmentAtmosphereSound
What I owned

Solo project · Product concept, interaction design, generative provider integrations, scene model, shader safeguards, and WebGL renderer.

Product model

Every project is a structured, editable preset with source media, treatments, shaders, sound, performance preferences, and lineage. It is not a flattened export.

Generative stack

OpenAI generates source images, ElevenLabs generates music, Anthropic creates guarded shader effects, and Gemini Veo supplies the video path.

Rendering

A shared Pixi and WebGL scene runtime combines uploaded or generated media with motion analysis that understands the source and parameterized GLSL effects.

Safety decision

Generated shader code passes static guards and compilation checks before it can enter the live rendering pipeline.

Performance

Explore, Labs, and Player use different frame rate budgets while sharing one scene and audio engine, preserving continuity without rendering everything at full rate.

Boundary

The working prototype prioritizes local use. Native packaging, cloud accounts, synchronization, and a real marketplace remain future work.
